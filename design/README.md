## 지도 UI 초안 (`map/index.html`)

**[브라우저에서 지도 UI 열기](https://dav3park.github.io/hopornot/design/map/)** · Pages를 이 브랜치(`design/map-ui`)로 켜야 열린다. 그 전에는 `design/map/index.html`을 받아서 더블클릭

기타줄 화면을 지도 위로 옮긴 버전. 4개 화면을 한 페이지에서 보고, 위 탭으로 하나씩 볼 수 있다.

1. **지도 홈**: 노선 위 정류장마다 탑승 확률 말풍선, 버스마다 지금 잔여석. 아래 시트 = AI 판단(몇 대 보낼지), 걸어가면 더 빨리 타는 정류장, 오는 버스 4대
2. **버스 선택**: 고른 버스만 강조. 내 정류장 도착 시 1석 / 5석 / 10석 이상 남을 확률 막대, 지나갈 정류장별 예상 잔여석
3. **정류장 비교**: 이동 시간까지 넣어 "가장 빨리 앉아서 탈 수 있는 정류장" 순위, 도보 경로 점선
4. **계속 붐빌 때**: 시간대별 탑승 확률 막대(70% 기준선, 지금 위치), 처음으로 탈 만한 버스, 출발 알림

같은 시안을 Figma에도 만들었다(지도 홈, 버스 선택 2개 화면. 지도·정류장 핀·버스 마커는 컴포넌트).

## 화면 흐름 (기존 프로토타입)

1. **로딩**: 2초 뒤 자동으로 넘어감 (탭하면 바로 넘어감)
2. **노선 선택**: 5100 / M5107 / 1112
3. **도착 순서 (기타줄)**
   - 가로줄 = 정류장, 세로줄 = 내 정류장으로 오는 버스 한 대
   - 점 색 = 그 정류장에서의 탑승 확률 (진한 파랑 70% 이상 / 연한 파랑 40~69% / 주황 40% 미만)
   - 위 카드 = AI 판단: **몇 대 보내야 하나**, **어디까지 걸어가면 더 빨리 타나**
   - 정류장 이름을 누르면 내 정류장이 바뀜
4. **실시간 수평선**: 기타줄에서 버스를 누르면 전환됨
   - 내 버스는 가운데 고정, 노선이 흘러감
   - 좌우로 밀면 앞뒤 정류장과 정류장별 탑승 확률을 볼 수 있음 (가운데 가까울수록 커짐)
   - 아래 **빈자리 예측 표**: 다음 정류장 3곳에서 1석 / 5석 / 10석 이상 남을 확률

## 주의

- 정류장 이름, 버스 위치, 탑승 확률, 소요 시간은 **전부 샘플 데이터**다. 실제 API와 예측 모델 결과로 바꿔야 함
- 추천 기준은 탑승 확률 70%
