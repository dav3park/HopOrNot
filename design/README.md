## 화면 흐름

1. **로딩**: 2초 뒤 자동으로 넘어감 (탭하면 바로 넘어감)
2. **노선 선택**: 5100 / M5107 / 1112
3. **도착 예측 (기타줄)**
   - 가로줄 = 정류장, 세로줄 = 내 정류장으로 오는 버스 한 대
   - 위 표 = 버스별 **지금 잔여석**과 내 정류장 **도착 시 1석 / 5석 / 10석 이상 남을 확률**
   - 표에서 1/5/10석 행을 누르면 기준이 바뀌고, 점 색과 AI 판단이 그 기준을 따름
   - 점 색 = 그 정류장 도착 시 기준 좌석 이상 남을 확률 (진한 파랑 70% 이상 / 연한 파랑 40~69% / 주황 40% 미만)
   - 위 카드 = AI 판단: **몇 대 보내야 하나**, **어디까지 걸어가면 더 빨리 타나**
   - 버스 위 숫자 = 지금 잔여석. 정류장 이름을 누르면 내 정류장이 바뀜
4. **지난 기록**: 내 정류장에 버스가 실제로 몇 석 남기고 왔는지 시간표처럼 보여줌 (오늘 / 지난주 같은 요일)
5. **실시간 수평선**: 기타줄에서 버스를 누르면 전환됨
   - 위쪽 패널 = 지금 잔여석(검정)과 내 정류장 도착 시 확률(파랑)
   - 지나온 정류장은 지날 때 잔여석, 앞 정류장은 도착 시 예측
   - 내 버스는 가운데 고정, 좌우로 밀면 앞뒤 정류장을 볼 수 있음 (가운데 가까울수록 커짐)

## 표시 규칙

세 종류의 숫자를 어느 화면에서나 같은 모양으로 구분한다.

| 종류 | 모양 | 예 |
|---|---|---|
| 지금 (실측) | 검정 바탕, 흰 글자 | 지금 12석 |
| 도착 시 (예측) | 파랑 계열 | 도착 시 5석 이상 40% |
| 지난 기록 (실측) | 회색 | 지날 때 31석, 18:42 3석 |

## 주의

- 정류장 이름, 버스 위치, 잔여석, 확률, 지난 기록, 소요 시간은 **전부 샘플 데이터**다. 실제 API와 예측 모델 결과로 바꿔야 함
- 추천 기준은 선택한 좌석 수 이상 남을 확률 70%
