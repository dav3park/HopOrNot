# HopOrNot 디자인 시안

## 바로 보기 (클릭 한 번)

**[브라우저에서 프로토타입 열기](https://dav3park.github.io/hopornot/design/prototype/)**

- 폰에서도 열린다. 설치할 것 없음
- 이 링크는 리포 주인이 GitHub Pages를 켜야 열린다: **Settings → Pages → Source: Deploy from a branch → Branch: `design/bus-route-mockup`, 폴더 `/ (root)` → Save**. 1~2분 뒤부터 열림
- 그 전에는 `design/prototype/index.html`을 받아서 더블클릭하면 똑같이 돌아간다 (파일 하나에 다 들어 있음)

## 화면 흐름

1. **로딩**: 2초 뒤 자동으로 넘어감 (탭하면 바로 넘어감)
2. **노선 선택**: 5100 / M5107 / 1112
3. **도착 순서 (기타줄)**
   - 가로줄 = 정류장, 세로줄 = 내 정류장으로 오는 버스 한 대
   - 점 색 = 그 정류장에서의 탑승 확률 (진한 파랑 70% 이상 / 연한 파랑 40~69% / 주황 40% 미만)
   - 위 카드 = AI 판단: **몇 대 보내야 하나**, **어디까지 걸어가면 더 빨리 타나**
   - 정류장 이름을 누르면 내 정류장이 바뀜
4. **실시간 수평선**: 기타줄에서 버스를 누르면 전환됨
   - 내 버스는 가운데 고정, 노선이 흘러감
   - 좌우로 밀면 앞뒤 정류장과 정류장별 탑승 확률을 볼 수 있음 (가운데 가까울수록 커짐)

## 주의

- 정류장 이름, 버스 위치, 탑승 확률, 소요 시간은 **전부 샘플 데이터**다. 실제 API와 예측 모델 결과로 바꿔야 함
- 추천 기준은 탑승 확률 70%
