실제 API, 지도 SDK, 위치 권한 요청, 도보 경로 엔진은 미연결입니다. mock ID 및 정류장은 예시이며 실제 운행 정보를 보장하지 않습니다. 디자인 교체 지점과 연동 항목은 README 및 API 계약에 정리했습니다.

SDK 호환성 확인에 사용한 공식 문서: [Expo SDK 58](https://docs.expo.dev/versions/v58.0.0/), [Router 설치](https://docs.expo.dev/router/installation/), [AsyncStorage](https://docs.expo.dev/versions/v58.0.0/sdk/async-storage/), [Safe Area](https://docs.expo.dev/versions/v58.0.0/sdk/safe-area-context/).

## 실제 GBIS 노선·정류장 연결 · 2026-11-12 최신

- 메인에서 예시 노선도와 지도 전환 버튼을 제거하고 실제 카카오맵만 표시합니다.
- GBIS 공식 공개 지도 응답에서 실제 5100(200000115), 1112(234000016), M5107(234001243)의 상하행 정류장과 도로 경로를 수집해 번들에 포함했습니다. 임의 직선이나 가짜 GPS를 사용하지 않습니다.
- 경유 전용 지점을 탑승 정류장에서 제외하고 회차 정류장은 귀환 방향에서도 선택할 수 있게 했습니다. 공식 전체 순번을 보존합니다.
- Chrome 실제 카카오 SDK·타일로 노선별 223/355/323개 경로 점과 색을 확인했습니다. 청명역3번출구 좌표 37.2588152, 127.0786351이 실제 오버레이에 전달되는 것을 확인했습니다. M5107 귀환 방향 334개 경로 점, 상단 노선 버튼·방향 전환도 확인했습니다. 페이지 오류 없음.
- 밀집한 정류장은 선택된 말풍선을 우선 표시하고, 겹치는 다른 정류장은 접근성 이름을 가진 점으로 유지합니다. 지도 확대·선택 시 이름과 확률을 표시합니다. 지도 컨테이너를 별도 stacking context로 두어 SDK 벡터가 앱 버튼을 가리지 않게 했습니다.
- 데이터/추천/실제 노선 정합성 테스트 30개 통과. 모든 탑승 정류장이 공식 도로 경로에서 150m 이내인지, 방향별 경로·순번·회차 지점 및 좌표 범위를 검증했습니다.
- 확률·잔여석·도착 차량은 여전히 예시이며 상단에 실제 노선/예시 확률을 구분합니다. 실제 차량 GPS를 합성하지 않습니다. 실제 도보 경로가 없으므로 실제 정류장에 예시 도보 추천을 붙이지 않습니다.

## 정류장 점과 노선 구분색 개선 · 2026-11-12

- 점과 말풍선을 별도 오버레이로 분리했습니다. 점은 고정 44px 클릭 영역, 17px 원형 표시와 선택 시 21px 강조를 유지하고 말풍선 크기 변화에 영향을 받지 않습니다.
- 표시용 점은 100m 이내 가까운 해당 방향 경로에 정렬하며 원본 정류장 좌표·선택 데이터는 변경하지 않습니다. 네이티브 지도에도 별도 점/이름 라벨을 적용했습니다.
- 노선은 5100 빨강 #EC0000, M5107 파랑 #245EC7, 1112 청록 #087F72로 구분합니다. 비선택 노선의 불투명도도 높였습니다.
- 경로가 정류장보다 먼저 도착해 전체 경로 중심을 잡은 경우, 정류장 좌표 도착 후 최초 중심을 다시 맞추도록 수정했습니다.
- 실제 카카오 SDK에서 세 노선 각각 지도 레벨 4/7/5로 확대·축소하며 표시된 모든 점의 중심 오차가 2px 미만이고 클릭 영역이 44px임을 확인했습니다. 세 노선의 정류장 점 클릭도 통과했고 페이지 오류는 없었습니다.
- 코어/정류장 정렬/네이티브 씬 테스트 32개 통과. 최신 스크린샷은 `station-dots-5100.png`, `station-dots-1112.png`, `station-dots-M5107.png`입니다.


## 방향 탭·연속 표시 번호 · 2026-11-12

- 지도 홈에 목적지/국제캠퍼스 방향 탭을 추가하고 노선별 서울 목적지를 구분했습니다. 기존 방향별 데이터 조회와 경로에 연결하며, 방향 변경 시 정류장·차량 선택과 지도 초기 범위를 해제합니다.
- M5107 원본 30번은 시청교차로(경유), 29번은 서울시청, 31번은 신한은행본점입니다. 경유 지점을 제외하면서 원본 순번을 노출했던 이유로 번호가 건너뛰었습니다. 화면에는 각각 9번·10번으로 연속 표시하며 원본 순번과 stationId는 유지합니다.
- 지도 말풍선·네이티브 라벨·정류장 검색의 표시 번호를 통일했습니다. 검색 결과도 필터링 이전 목록의 번호를 사용합니다.
- 데이터/방향/표시 번호 테스트 34개, 기존 UI 테스트 29개, 타입 검사·린트 통과.
