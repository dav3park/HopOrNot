# HopOrNot 원본 디자인·모델 계획 연결

디자인: [design/seat-probability-view](https://github.com/dav3park/HopOrNot/tree/design/seat-probability-view)
모델: [docs/ml-model-plan/ml/README.md](https://github.com/dav3park/HopOrNot/blob/docs/ml-model-plan/ml/README.md)

이전의 카드형 ‘부분 반영’ 구현은 기본 화면에서 제외했습니다. 현재는 디자인 브랜치의 prototype/index.html 화면 템플릿, 390×844 배치, SVG와 전환 상태를 직접 가져와 React Native로 렌더링합니다. 원본 보관 및 변경 범위는 [design-reference](../design-reference/README.md), 실제 브라우저 검증은 [verification](verification.md)에 있습니다.

## 화면

- 원본 로딩 화면과 버스 슬라이드, 2.4초 후 노선 선택(탭하면 즉시 이동).
- 원본 노선 카드 → 버스별 관측/1·5·10석 확률 표와 세로 기타줄.
- 좌석 기준 변경, 정류장 변경, 버스 선택 시 회전·이동 전환.
- 원본 수평 노선: 중심 차량, 가까운 정류장 확대, 좌우 이동, 기점/내 버스/종점 이동.
- 원본 과거 기록: 오늘/지난주 같은 요일, 요약 통계와 관측 행. 빈 날짜에는 기록을 생성하지 않음.
- 더보기에서 기존 즐겨찾기·방향·정류장 검색·시간대 전망·대안·품질/출처·개발 시나리오 접근.

예시 배지와 더보기 버튼 외의 상위 카드/앱 바를 덧붙이지 않습니다. 390×844 배치를 뷰포트에 비례 축소/확대하며, 데스크톱의 32px 여백·최대 1.25배·44px 모서리도 원본 기준입니다. 고정 디자인의 글꼴 크기를 유지하며 큰 글꼴을 사용하는 상세 화면은 더보기에서 제공합니다.

## 데이터와 표현

원본의 임의 확률 함수와 날짜별 가상 기록 생성은 사용하지 않습니다. 기존 repository/query로 받은 차량 최대 3대·확률·실제 관측·과거 기록을 연결했습니다. mock에서는 기존 fixture와 데모 기준 시각(2026-11-04 08:00)을 사용합니다. 차량 움직임은 mock에서만 시연하며 ‘예시 재생’으로 표시합니다. live에 실제 위치 계약이 없으므로 임의 위치를 실시간으로 표시하지 않습니다.

모델의 4단계 분포는 SeatDistribution과 일치합니다. 단일 검증/누적 함수로 1/5/10석 이상을 표시합니다. null은 —, 잘못된 분포는 오류, 유효한 0은 0%입니다. 현재 관측/예측/과거 관측을 원본의 검정/파랑/회색으로 구분합니다. 선택 정류장의 핵심 분포가 null/오류이면 부가 경로 예측으로 덮지 않습니다.

‘이번 버스 타세요’·‘모두 만석’처럼 대기열을 알지 못한 상태의 단정은 좌석 여유 참고 문구로 조정했습니다. 70%는 비교 기준이며 탑승 보장/모델 품질 기준이 아닙니다. n대 독립 가정 결합 확률과 도보시간 추측은 추가하지 않았습니다. 실제 ETA만 사용하며 누락 시 ETA 없음으로 표시합니다. 가상 노선/정류장 ID와 예시 정류장 이름을 유지합니다.

## 백엔드 협의

선택 필드 제안:

- `currentObservation?: { remainingSeats; observedAt } | null`
- `stationPredictions?: { stationId; stationSequence; distribution; source; quality }[]`

실제 차량 위치, 차량별 과거 정류장 관측, 다음 정류장 ETA는 추가 계약이 필요합니다. 모델의 출발값 대체·범위 라벨·애매한 라벨을 직접 관측 기록에 섞지 않아야 합니다. 새벽 3시 기준 학습일과 UI의 서울 달력 날짜는 다른 용도이므로 history 날짜 경계를 합의해야 합니다.

앱은 모델 서버를 직접 호출하지 않고 서비스 API를 받습니다. 서버 주소·공식 노선/방향/정류장 코드·위치·데이터 최신성 기준·인증·실제 도보 경로가 아직 필요합니다. 모델 학습·서버 구현·원격 반영은 수행하지 않았습니다.
