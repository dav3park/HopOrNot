# 실제 경기버스 노선 데이터

카카오맵에 표시하는 기본 노선·정류장 자료는 [경기버스 공식 지도](https://www.gbis.go.kr/gbis2014/schBus.action)에서 2026-11-12 수집했습니다. 공식 홈페이지의 노선/경유/정류소 다운로드 자료로 노선 ID도 교차 확인했습니다. 모델 계획 브랜치의 수집기 설정과 동일한 ID입니다.

| 노선  | GBIS 노선 ID | 서울 방향 정류장 | 캠퍼스 방향 정류장 | 도로 경로 점 수 (서울/캠퍼스) |
| ----- | ------------ | ---------------: | -----------------: | ----------------------------: |
| 5100  | 200000115    |               16 |                 20 |                     223 / 268 |
| 1112  | 234000016    |               26 |                 27 |                     355 / 380 |
| M5107 | 234001243    |               11 |                 11 |                     323 / 334 |

## 출처와 처리

- 공식 지도에서 사용하는 공개 요청: `POST https://www.gbis.go.kr/gbis2014/schBusAPI.action`.
- `cmd=searchRouteJson&routeId=...`: 방향별 정류장 ID·이름·방문 순번·좌표를 추출합니다. 응답의 실시간 차량·차량 번호 정보는 저장하지 않습니다.
- `cmd=searchMapLineJson&routeId=...`: 공식 도로 경로의 shape 좌표를 추출합니다. 경기버스 지도 구현과 동일하게 `type=2` 링크 메타데이터를 제외하고 경로 점을 사용합니다.
- GBIS 지도의 EPSG:3857 좌표를 WGS84 위도·경도로 변환합니다. 임의 GPS, 임의 정류장 이름, 정류장 사이의 직선 경로를 만들지 않습니다.
- `stationTp=6`인 경유 전용 지점은 탑승 정류장에서 제외합니다. 회차 정류장은 귀환 방향에서도 선택할 수 있도록 포함합니다. 내부 방문 순번은 공식 전체 운행 순번을 보존합니다. 화면에는 방향별 탑승 정류장의 순서대로 1부터 연속 번호를 표시합니다. 예를 들어 M5107의 원본 29번 서울시청과 31번 신한은행본점은 화면에서 각각 9번과 10번입니다. 원본 30번 시청교차로는 경유 전용 지점입니다.
- 서울 방향은 공식 `up`, 국제캠퍼스 방향은 `down`입니다. 청명역은 방향에 따라 3번출구/4번출구로 구분됩니다.

## 갱신

```sh
python3 scripts/sync-gbis-routes.py
```

표준 Python 라이브러리만 사용합니다. 공개 지도 요청 6회로 세 노선을 갱신하고 `src/data/gbis/routes.json`에 원자적으로 저장합니다. 실패하면 기존 파일을 보존합니다. 수집 시각과 출처 URL도 JSON에 포함합니다. 현재 공개 웹 응답 형식에 의존하므로 GBIS 변경 시 스크립트를 확인해야 합니다. 운영 서버에서는 [정식 GBIS Open API](https://www.gbis.go.kr/gbis2014/publicService.action?cmd=openApiInfo)를 사용하는 것이 적절합니다.

## 실제 자료와 예시의 구분

노선 경로·정류장 ID·이름·좌표는 공식 자료입니다. 기본 모드의 도착 예정 차량·잔여석·확률은 기존 화면 예시이며, 상단에 **실제 노선 · 예시 확률**을 표시합니다. 이 차량에 임의 GPS를 붙이지 않습니다. 실제 정류장 간 도보 경로도 확보하지 않았으므로 예시 도보 추천을 실제 정류장에 전용하지 않습니다.

실제 모델 확률·실시간 차량 위치는 기존 API 모드 계약으로 연결할 수 있습니다. Native 앱에서 실제 카카오맵을 실행하려면 별도의 Native 앱 키 등록과 개발 빌드가 필요합니다. JavaScript 키로 확인한 웹 지도는 실제 타일·노선·정류장 표시까지 검증했습니다.
