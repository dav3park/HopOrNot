# 지도 중심 UI + Flame

2026-11-12 사용자가 제공한 지도 홈·버스 상세·정류장 비교·시간대 전망 4개 이미지를 최신 레이아웃 기준으로 사용합니다. 이전의 브랜치 배치 유지 요청은 이번 명시적인 지도 중심 재구성 요청으로 대체됐습니다. 기존 ExactDesign 구현과 원본 자료는 참고용으로 보관합니다.

## 구성

- 앱 시작 시 지도 홈: 상단 노선 탭과 1/5/10석 필터, 정류장 이름·확률 말풍선, 버스와 현재 좌석, 아래 흰색 패널.
- 버스 선택: 선택 차량 강조, 잔여석 관측값, 도착 좌석 확률 막대, 정류장별 확률.
- 정류장 비교: 지도와 도보 이동을 고려한 후보 목록. 검증된 도보 경로·도착 가능 시간·70% 이상 확률·현재 정류장보다 빠른 도착 조건을 만족한 후보만 추천.
- 시간대 전망: 70% 기준선·현재 시각·확률 막대, 다가오는 차량. 알림이나 위치 추적 기능을 구현한 것처럼 표시하지 않습니다.

## 색과 글꼴

Flame md의 팔레트를 사용합니다. 노선은 최신 구분 요청에 따라 5100 #EC0000(빨강), M5107 #245EC7(파랑), 1112 #087F72(청록)으로 표시합니다. 노선 구분색만 별도로 쓰고 나머지 UI는 Flame 팔레트를 유지합니다. 좌석 확률 70% 이상은 #EC0000, 40–69%는 #EA6F5D, 40% 미만은 #F5DECF입니다. 정보 카드는 #DEEDF2, 선택 배경은 #FBF1EA, 기본 카드는 흰색입니다. 시스템 sans-serif와 700 굵기를 사용합니다. 전용 Santander 폰트 파일은 포함하지 않습니다.

## 구현과 데이터

- `src/features/map-home/home.tsx`: 메인 상태·네 패널·조회 연동.
- `src/features/map-home/styles.ts`: Flame 스타일.
- `src/features/map-home/demo.ts`: 좌석 확률·도착 차량의 예시 값. `schematic.tsx`는 참고용으로만 보관하며 렌더링하지 않습니다.
- `src/maps/route-map.web.tsx`: 카카오 지도와 정류장 확률 말풍선·노선별 선.
- `src/maps/native-scenes.ts`, `route-map.tsx`: 네이티브 지도에서도 동일한 색상·정류장 확률을 표시.

모든 모드에서 카카오맵을 기본으로 사용합니다. `src/data/gbis/routes.json`에 포함한 GBIS 공식 노선·정류장 좌표를 기본 지도에 사용합니다. 노선별 도로 경로는 정류장 사이의 임의 직선이 아닙니다. 실시간 차량 GPS를 합성하지 않으며, 확률 예시는 별도로 표시합니다. map 화면의 기존 URL도 지도 홈으로 연결됩니다.

같은 분포에서 1/5/10석 확률을 계산합니다. 빈 데이터는 —, 잘못된 분포는 오류로 구분하고 보정하지 않습니다. 도착 확률은 남은 좌석의 예측이며 대기 인원을 포함한 탑승 보장이 아닙니다. 현재 잔여석을 미래 좌석 수로 전용하지 않습니다.

최신 실제 지도 화면은 `docs/screenshots/real-kakao-M5107.png`, `real-kakao-overview.png`, `real-kakao-return.png`입니다. 이전 4개 패널 디자인 시안은 `map-*.png`로 보관했습니다.


정류장 점은 말풍선과 분리해 항상 표시하고 44px 클릭 영역을 둡니다. 말풍선은 점의 옆으로 배치하며 밀집 시 말풍선만 숨깁니다. 공식 정류장 좌표는 유지하고 표시용 점만 100m 이내의 가까운 해당 방향 노선에 정렬합니다. 원래 좌표와 노선이 크게 다르면 임의로 이동하지 않습니다.


지도 홈의 노선 탭 아래에서 서울 목적지/국제캠퍼스 방향을 선택합니다. 서울 목적지는 노선에 따라 강남역(5100), 강변역(1112), 서울역(M5107)으로 표시합니다. 방향 변경 시 이전 정류장·차량 상세 선택을 해제하고 해당 방향의 경로·정류장·조회 키를 사용합니다. 지도와 정류장 검색의 화면 번호는 방향별로 연속 표시하고 API 조회용 원본 방문 순번은 유지합니다. 검색해도 화면 번호는 원래 방향별 목록을 기준으로 유지합니다.
