# HopOrNot iOS 앱

SwiftUI 앱. 추론 서버(`ml/serve`)를 직접 부르고, 서버가 없으면 앱에 넣어 둔 과거 실제 데이터(데모)로 동작한다.

## 화면

| 화면 | 내용 |
| --- | --- |
| 노선 선택 | 노선 카드 3개 |
| 노선 (정류장 목록) | 네이버·카카오 버스처럼 한 방향의 정류장 목록 위에 지금 달리는 버스를 놓는다. 정류장 사이를 가는 버스는 그 사이에, 정류장에 도착한 버스는 그 정류장 줄에 "도착"으로. 영통행 맨 위에는 고속도로에서 서울로 들어오는 버스("양재IC 지남")가 있다 |
| 정류장을 누르면 | 그곳이 내 정류장이 되고 위에 **AI 판단**("이번 버스 타세요" / "1대 보내고 다음 버스" + 탈 확률)이 고정된다. 내 정류장으로 오는 버스 옆에 **탈 확률**(가까운 4대는 앞 버스를 보내는 경우까지 누적, 그 뒤는 1석 이상 확률). 지난 버스는 흐리게 |
| AI 판단을 누르면 | 상세: 오는 버스별 1·5·10·20석 이상 확률, 탈 확률 높은 정류장 |
| 지도 버튼 | 내 정류장 주변 노선(경기버스 공식 도로 경로)과 오는 버스 |

"탈 확률"은 앞 버스를 못 타면 그 버스 좌석만큼 내 앞 인원이 줄어드는 것을 반영한다:
P(k번째 버스까지 탐) = P(내 앞 인원 < 1–k번 버스 좌석 합) (`ml/src/live.py`).

## 실행

```bash
open ios/HopOrNot.xcodeproj        # Xcode 26, iOS 17 이상
```

- 기본은 **데모** 데이터 (`HopOrNot/Demo/`, 11/20 18:10 실제 데이터). 설정(톱니바퀴)에서 **추론 서버**로 바꾸고 주소를 넣는다.
- 시뮬레이터에서 맥의 서버를 쓰려면: `cd ml && ssh -N -L 5432:127.0.0.1:5432 bus` 를 켜고 `uvicorn serve.app:app --port 8000`, 앱 주소는 `http://localhost:8000`.
- 실기기에서는 서버를 HTTPS로 열어야 한다 (`Config/Info.plist` 는 localhost만 http 허용).

데모 데이터 다시 만들기 (그 시각까지의 관측만 쓴다):

```bash
cd ml && python -m serve.demo_fixtures --at 2026-11-20T18:10
```

## 구조

```
ios/
├── HopOrNot.xcodeproj      # HopOrNot/ 폴더를 통째로 동기화 (파일 추가 시 프로젝트 수정 불필요)
├── Config/Info.plist       # ATS: localhost http 허용
└── HopOrNot/
    ├── App/                # 앱 진입, 개발용 스냅샷(-renderSnapshot)
    ├── Model/              # 서버 응답 모델, 데이터 소스(데모·서버), 판단 로직, 앱 상태
    ├── UI/                 # 노선 선택, 노선(정류장 목록), 상세, 지도, 버스 카드, 추천 정류장
    └── Demo/               # 데모 응답 (serve/demo_fixtures.py)
```

개발용 실행 인자 (Debug 빌드만): `-renderSnapshot` 노선 화면 전체를 PNG로 저장, `-selectStop M5107,영통행,36,광교` 정류장을 골라 시작.
