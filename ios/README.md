# HopOrNot iOS 앱

SwiftUI 앱. 추론 서버(`ml/serve`)를 직접 부르고, 서버가 없으면 앱에 넣어 둔 과거 실제 데이터(데모)로 동작한다.

## 화면

| 화면 | 내용 |
| --- | --- |
| 노선 선택 | 노선 카드 3개. 서울행·출근 / 영통행·퇴근으로 나누지 않는다 |
| 정류장 목록 | 노선 한 바퀴를 한 줄로: 캠퍼스(흐리게) → 출발권 정류장 → **고속도로(회색 레일, IC·JC·TG 이름 전부)** → 서울 정류장 → 고속도로 → 도착권 정류장 → 캠퍼스. 같은 이름 정류장이 오가는 길에 두 번 나오므로 서울행/영통행 표시와 "회차" 표시가 붙는다. 버스는 레일 위를 움직인다 (왼쪽에 지금 잔여석, 0석 빨강·1–9석 주황). 처음 열 때 지금 시간대 방향(오전 서울행, 오후 영통행) 정류장으로 스크롤. 데모는 17:50–18:10 실제 데이터를 2분 간격으로 재생, 서버는 30초마다 갱신 |
| 정류장 (목록에서 누르면) | **AI 판단** → **노선도/지도** → **오는 버스** (이번·다음 버스만, "버스 N대 더보기") → **탈 확률 높은 정류장** → **지난 7일 도착 잔여석** |
| 노선도 탭 | 오는 버스 4대가 열. 정류장마다 1석 이상 확률 점. 내 정류장 앞쪽은 버스가 오는 길 전체(고속도로 회색, IC 이름), 뒤쪽은 몇 줄 흐리게 |
| 지도 탭 | 노선 전체(경기버스 공식 도로 경로, 고속도로 회색)와 모든 정류장(확대하면 이름), 노선 위 다른 버스는 작은 점, 내 정류장으로 오는 버스는 번호(1 = 이번)와 탈 확률이 든 핀. 가까운 핀은 쌓아서 서로 가리지 않는다. "전체 노선" 버튼으로 노선 전체 보기 |
| 지난 7일 도착 잔여석 | 날짜 × 30분 칸의 평균 잔여석 (0석 빨강, 1–9석 주황, 10–19석 연한 파랑, 20석 이상 파랑). 옆으로 밀어 하루 전체를 보고, 칸을 누르면 값이 나온다 |

- **탈 확률**: P(k번째 버스까지 탐) = P(내 앞 인원 < 1–k번 버스 좌석 합) (`ml/src/live.py`).
- **예상 잔여석**: 단계 확률을 좌석 수 분포로 편 중앙값과 10–90% 범위.

## 접근 키를 앱에 넣기

폰에서 키를 입력하지 않아도 되게, 빌드할 때 키가 앱에 들어간다. 키는 **Git에 올라가지 않는** `Config/Secrets.xcconfig`에 둔다.

```bash
cp ios/Config/Secrets.example.xcconfig ios/Config/Secrets.xcconfig
# 키를 파일에 넣는다 (서버에서 읽기):
printf 'HOPORNOT_API_KEY = %s\n' "$(ssh bus 'grep ^API_KEY ~/hopornot-serve/.env | cut -d= -f2')" > ios/Config/Secrets.xcconfig
```

- 키가 들어 있으면 앱은 처음부터 **실서버 모드**로 시작하고 (주소 기본값 `https://54-116-10-20.sslip.io`), 없으면 데모로 시작한다. 설정에서 직접 넣은 키가 있으면 그것이 우선한다.
- 앱 파일(.app)을 받은 사람은 키를 꺼낼 수 있다. 개인·수업용으로는 충분하고, 키가 새면 서버 `.env`의 `API_KEY`를 바꾸고 앱을 다시 빌드한다.
- `Secrets.xcconfig`가 없어도 빌드는 된다 (키가 빈 값이라 데모로 시작).

## 실행

```bash
open ios/HopOrNot.xcodeproj        # Xcode 26, iOS 17 이상
```

- 기본은 **데모** 데이터 (`HopOrNot/Demo/`, 11/20 18:10 실제 데이터). 설정(톱니바퀴)에서 **추론 서버**로 바꾸고 주소를 넣는다.
- 시뮬레이터에서 맥의 서버를 쓰려면: `cd ml && ssh -N -L 5432:127.0.0.1:5432 bus` 를 켜고 `uvicorn serve.app:app --port 8000`, 앱 주소는 `http://localhost:8000`.
- 실기기에서는 서버를 HTTPS로 열어야 한다 (`Config/Info.plist` 는 localhost만 http 허용).

데모 데이터 다시 만들기 (그 시각까지의 관측만 쓴다):

```bash
cd ml && python -m serve.demo_fixtures --at 2026-11-20T18:10
```

## 구조

```
ios/
├── HopOrNot.xcodeproj      # HopOrNot/ 폴더를 통째로 동기화 (파일 추가 시 프로젝트 수정 불필요)
├── Config/Info.plist       # ATS: localhost http 허용
└── HopOrNot/
    ├── App/                # 앱 진입, 개발용 스냅샷(-renderSnapshot)
    ├── Model/              # 서버 응답 모델, 데이터 소스(데모·서버), 판단 로직, 앱 상태
    ├── UI/                 # 노선 선택, 정류장 목록(움직이는 버스), 정류장 화면, 노선도, 지도, 버스 카드, 지난 7일, 추천 정류장
    └── Demo/               # 데모 응답 (serve/demo_fixtures.py)
```

개발용 실행 인자 (Debug 빌드만): `-renderSnapshot` 노선 화면 전체를 PNG로 저장, `-selectStop M5107,36,광교` 정류장 화면으로 시작, `-openRoute M5107` 정류장 목록으로 시작, `-startMap` 지도 탭으로 시작, `-scrollTo history|buses|recommend` 그 카드로 스크롤.
